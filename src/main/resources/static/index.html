🐾 PetClean — API de Gestão para Pet Shops

Backend REST em Spring Boot construído a partir dos 6 épicos e das 25 histórias de usuário do relatório de Gestão Ágil (Kanban + XP): clientes, pets, agendamentos, estoque, dashboards e autenticação com sessão.

Autenticação

Faça login para liberar as rotas internas (US-01, US-02 e US-14). O cookie de sessão é reaproveitado pelo Swagger.

helen@petclean.com / petclean123
gestor@petclean.com / gestor123

Roteiro rápido de teste (US-01 → US-24)

MétodoRotaHistória
POST/loginUS-01 login com e-mail e senha (bcrypt — RNF-04)
GET/api/clientes?termo=MariaUS-04 consulta e filtro de clientes
POST/api/clientesUS-03 cadastro · US-15 bloqueio de CPF duplicado
DELETE/api/clientes/{id}US-06 exclusão com integridade referencial (RNF-09)
GET/api/pets?termo=ThorUS-08 filtro por nome do pet ou tutor
GET/api/agendamentos/agenda?data=2026-11-05US-12 agenda do dia
POST/api/agendamentosUS-11 cadastro · US-17 conflito de horário
PATCH/api/agendamentos/{id}/statusUS-13 status · US-16 cancelamento
GET/api/produtos/estoque-criticoUS-20 alerta de estoque crítico
PATCH/api/produtos/{id}/movimentarUS-19 entrada/saída de estoque
GET/api/dashboard?periodo=semanalUS-22 KPIs · US-23 gráfico · US-24 estoque crítico
POST/logoutUS-14 encerrar sessão
